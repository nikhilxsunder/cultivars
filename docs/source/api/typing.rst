cultivars.typing
================

.. automodule:: cultivars.typing
   :no-members:

Categorical options are declared as PEP 695 ``type`` aliases over
``Literal`` so that the permitted strings are visible to type checkers and
to autocomplete. Pass the string; the alias is for annotation.
