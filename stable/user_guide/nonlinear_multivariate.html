Nonlinear, time-varying and regime-switching VARs#

Every model on this page lets the VAR coefficient stack move. They differ in what it moves with: an observed state (threshold, smooth-transition and functional-coefficient VARs), the quantile level (quantile VAR), the date (time-varying-parameter VARs, Bayesian), or a latent Markov chain (Markov-switching VAR). Use them to ask whether transmission differs across regimes, states, tails or periods. The constant-coefficient VAR is in Vector autoregressions, Bayesian constant-coefficient VARs (including stochastic volatility with fixed coefficients) in Bayesian VARs, and the univariate counterparts in Nonlinear and regime-switching univariate models.

The likelihood-based results (TVAR, STVAR, MS-VAR) rank against one another and against a linear VAR with compare. The kernel, quantile and Bayesian results report no llf, no n_params and no information criteria, and have no compare.

The common contract: every response names where it is asked#

A nonlinear VAR has no single companion matrix. Every propagation method here takes a keyword that says which linear system to propagate, and the answer holds that system frozen over the horizon:

Result

Keyword

Methods

TVARResult, STVARResult

regime="lower" or "upper"

irf, fevd, ma_representation, equation

FunctionalCoefficientVARResult

u=<state value>

irf, coefficients_at

QVARResult

quantile=<level>

irf, ma_representation, coefficients, forecast

TVPVARResult, TVPSVARResult

t=<row> (position)

coefficients_at, impact, irf

MarkovSwitchingSVARResult

regime=<int>

irf, impact, structural

These are linearizations: exact only while the shock does not move the transition variable across the split, the state does not move, the parameters do not drift, or the chain stays put. Generalized impulse responses that average over histories and future shocks (Koop, Pesaran and Potter, 1996) are not implemented for any model on this page. The generalized_irf on linear VAR results is the Pesaran-Shin order-invariant response of a linear system, a different object.

Threshold VAR#

The model#

Two complete VARs glued along a threshold on an observed variable (Tsay, 1998):

\[\begin{split}y_t = \begin{cases} c_L + \sum_{i=1}^{p} A_{L,i}\, y_{t-i} + u_t, & u_t \sim N(0, \Sigma_L), \quad z_t \le r, \\ c_U + \sum_{i=1}^{p} A_{U,i}\, y_{t-i} + u_t, & u_t \sim N(0, \Sigma_U), \quad z_t > r, \end{cases} \qquad z_t = s_{t-d},\end{split}\]

where \(s\) is a column of the system (self-exciting) or an external series. The likelihood is a step function of \(r\), so the estimator is an exhaustive grid over trimmed quantiles of \(z\) (and over delays 1..order when the delay is left open), with regime-wise least squares at each candidate. The criterion is the total Gaussian log-likelihood with a separate covariance per regime, so the noisiest equation does not choose the split.

The running example is persistent and quiet when y1’s lag is at or below zero, and mean-reverting and louder above it:

import numpy as np
from cultivars.multivariate.nonlinear.threshold import TVAR
from cultivars.multivariate.reduced_form.vector_autoregression import VAR

rng = np.random.default_rng(7)
y = np.zeros((300, 2))
calm = np.array([[0.6, 0.0], [0.2, 0.5]])
tight = np.array([[-0.2, 0.3], [0.1, -0.3]])
for t in range(1, 300):
    above = y[t - 1, 0] > 0.0
    y[t] = (tight if above else calm) @ y[t - 1]
    y[t] += (1.5 if above else 1.0) * rng.standard_normal(2)

tvar = TVAR(y, order=1, transition_variable="y1", delay=1).fit()
print(round(tvar.threshold, 3), tvar.n_lower, tvar.n_upper, tvar.nobs, tvar.n_params)
print(tvar.lower_coefficients[0].round(2))
print(tvar.upper_coefficients[0].round(2))
print(np.diag(tvar.lower_sigma_u).round(2), np.diag(tvar.upper_sigma_u).round(2))

irf is orthogonalized by default with the regime’s own Cholesky factor, so the ordering of names is an identifying assumption and the impact differs across regimes because the covariances do. Smooth-transition VAR#

The model#

\[y_t = \bigl(1 - G(z_t)\bigr)\bigl(c_L + \textstyle\sum_i A_{L,i} y_{t-i}\bigr) + G(z_t)\bigl(c_U + \textstyle\sum_i A_{U,i} y_{t-i}\bigr) + u_t, \qquad u_t \sim N(0, \Sigma),\]

with \(G(z) = (1 + e^{-\gamma (z - c)/\sigma_z})^{-1}\) (transition="logistic", directional regimes) or \(G(z) = 1 - e^{-\gamma (z - c)^2/\sigma_z^2}\) (transition="exponential", the “upper” regime is both tails). The speed gamma is per standard deviation of the transition variable. Conditional on \((\gamma, c)\) the model is linear, so the regime coefficients come from one weighted least-squares solve and only the pair is searched, multi-start and derivative-free, on the log-determinant of the residual covariance (Teräsvirta and Yang, 2014). The innovation covariance is common across regimes: smooth weights never partition the sample, so there is no subsample to estimate a per-regime covariance from.

from cultivars.multivariate.nonlinear.smooth_transition import STVAR

rng = np.random.default_rng(1)
x = np.zeros((400, 2))
for t in range(1, 400):
    g = 1.0 / (1.0 + np.exp(-2.0 * x[t - 1, 0]))
    x[t] = ((1.0 - g) * 0.6 - g * 0.3) * x[t - 1] + rng.standard_normal(2)

stvar = STVAR(x, order=1, transition_variable="y1").fit()
print(stvar.transition, round(stvar.gamma, 2), round(stvar.transition_scale, 2))
print(round(stvar.threshold, 2), stvar.n_params, stvar.is_effectively_abrupt)
print(np.diag(stvar.lower_coefficients[0]).round(2))
print(np.diag(stvar.upper_coefficients[0]).round(2))
w = stvar.regime_weight
print(round(float(np.mean((w > 0.1) & (w < 0.9))), 2))

Functional-coefficient VAR#

The model#

Every coefficient is an unknown smooth function of the state (Chen and Tsay, 1993; Cai, Fan and Yao, 2000):

\[y_t = c(z_t) + \sum_{i=1}^{p} A_i(z_t)\, y_{t-i} + u_t, \qquad z_t = s_{t-d}.\]

At each grid point \(u\) one Epanechnikov-weighted local-linear least squares on \([x_t,\ x_t (z_t - u)]\) gives the level and slope of every coefficient; the level is the reported curve. The bandwidth is chosen by exact leave-one-out cross-validation around the Silverman rule unless you state it. There is no likelihood; the complexity measure is effective_params, the trace of the smoother matrix.

On the smooth-transition sample, the own-lag curve of y1 falls from the lower regime’s value toward the upper regime’s as the state rises:

print([round(v, 2) for v in fcvar.state_range], fcvar.curves.shape)
curve = fcvar.coefficient_curve("y1", "y1.L1")

coefficients_at(u) interpolates linearly between grid points and raises SpecificationError for a state outside state_range: kernel estimates do not extrapolate. forecast() takes no arguments and is one step only, because the state for \(T + 1\) is already observed at \(T\).

Quantile VAR#

The model#

Each conditional quantile is linear in the system’s lags, with its own coefficient stack at every level (White, Kim and Manganelli, 2015):

\[Q_\tau(y_{i,t} \mid y_{t-1}, \ldots, y_{t-p}) = c_i(\tau)' d_t + \sum_{l=1}^{p} a_{i,l}(\tau)' y_{t-l},\]

estimated by the Koenker and Bassett (1978) check-loss program, solved exactly as a linear program by HiGHS, equation by equation and level by level. There is no error term and no innovation covariance.

The example is a growth-at-risk system in which financial conditions fci scale the downside shocks to growth (Adrian, Boyarchenko and Giannone, 2019):

from cultivars.multivariate.nonlinear.quantile import QVAR

rng = np.random.default_rng(8)
g = np.zeros((400, 2))
for t in range(1, 400):
    fci = 0.8 * g[t - 1, 1] + 0.5 * rng.standard_normal()
    growth = 0.3 * g[t - 1, 0] - 0.2 * g[t - 1, 1]
    growth += np.exp(0.5 * g[t - 1, 1]) * 0.5 * rng.standard_normal()
    g[t] = [growth, fci]

qvar = QVAR(g, order=1, names=["growth", "fci"]).fit(quantiles=(0.1, 0.5, 0.9))
print(qvar.quantiles, qvar.coefficient_stacks.shape, qvar.nobs)
for tau in qvar.quantiles:
    print(tau, round(qvar.coefficients(tau)[0, 0, 1], 3))
print({k: round(v, 3) for k, v in qvar.pseudo_r_squared(0.1).items()})
print(round(qvar.crossing_share, 4), qvar.stability_profile().round(2))
print(qvar.forecast(0.1).round(3), qvar.irf(3, quantile=0.1)[:, 0, 1].round(3))

The coefficient of growth on lagged fci is -0.53 at the 10th percentile and -0.26 at the median: the downside reacts more. Each accessor (coefficients, deterministic, quantile_path, pseudo_r_squared, irf, forecast) takes a level that was estimated (to within 1e-9) and raises for any other; a new level is a new fit.

What is deliberately missing: llf and information criteria (check loss is not a likelihood; pseudo_r_squared is the Koenker and Machado, 1999, \(R^1\), local to its level), an orthogonalized irf (no covariance to factor; irf propagates one level’s coefficients as if they were the law of motion), and multi-step forecasts (a quantile of quantiles is not the multi-step quantile; fit direct regressions per horizon instead). Separately fitted levels can cross; crossing_share measures it and nothing is rearranged.

Time-varying-parameter VARs#

The model#

The stacked coefficients follow a random walk and, under stochastic volatility, so do the log variances (Cogley and Sargent, 2005; Primiceri, 2005):

\[y_t = X_t' \beta_t + u_t, \qquad \beta_t = \beta_{t-1} + \eta_t, \quad \eta_t \sim N(0, Q),\]
\[u_t \sim N(0, \Sigma_t), \qquad \Sigma_t = A^{-1} H_t A^{-\top}, \qquad H_t = \mathrm{diag}(e^{h_t}), \qquad h_t = h_{t-1} + \zeta_t, \quad \zeta_t \sim N(0, W).\]

TVPVAR holds \(\Sigma_t = \Sigma\). Estimation is Gibbs sampling on the package’s state-space layer: each coefficient-path draw is one Durbin and Koopman (2002) simulation-smoother pass, the covariances are conjugate inverse-Wisharts, and the volatility block is Kim, Shephard and Chib (1998) with a diagonal \(W\) as in Cogley and Sargent.

Priors#

Following Primiceri, a training sample is split off the front, its OLS estimates calibrate the priors, and it is then discarded:

  • initial state \(\beta_0 \sim N(\hat b_0, 4 \hat V_0)\) from the training OLS;

  • drift covariance \(Q\) inverse-Wishart with scale \(k_Q^2 \nu_Q \hat V_0\), \(\nu_Q = \max(\tau, D + 2)\);

  • \(\Sigma\) inverse-Wishart centred on the training covariance with \(k + 2\) degrees of freedom;

  • under SV, each diagonal entry of \(W\) inverse-Gamma with scale set by k_vol.

k_drift (Primiceri’s \(k_Q\)) and k_vol (\(k_W\)) both default to 0.01. At that default a coefficient that drifts by several tenths over a few hundred observations is shrunk to a few hundredths. Vary them; values of 0.05 to 0.3 let slow drift through.

A minimal fit#

The own-lag coefficient of y1 drifts from 0.1 to 0.8 and its shock standard deviation from 0.5 to 2. The draw counts below keep the example fast; real work needs the defaults (2000 draws, 1000 burn-in) or more.

from cultivars.multivariate.nonlinear.time_varying import TVPSVAR, TVPVAR, TVPVARSV

d = np.zeros((120, 2))
for t in range(1, 120):
    a = 0.1 + 0.7 * t / 120

print(path[[0, -1]].round(2))
print(tvp.coefficients_at(tvp.nobs - 1).round(2))

Identification: TVPSVAR#

TVPSVAR applies a recursive (Cholesky) identification at every date. How the ordering is declared depends on the source:

  • Homoskedastic source. The ordering is applied to the posterior-mean covariance at identification time, and any permutation is accepted through order=. The impact is the same at every date.

  • SV source. The triangular \(A\) was the estimation: \(A\) and the volatilities were drawn in the order of names. The impact at date \(t\) is the posterior mean of \(A^{-1} H_t^{1/2}\), so it drifts with the volatilities. Passing order= raises SpecificationError; to change the ordering, reorder the columns and refit.

ssvar = TVPSVAR(sv).identify()
last = ssvar.nobs - 1
print(np.diag(ssvar.impact(0)).round(2), np.diag(ssvar.impact(last)).round(2))
print(ssvar.irf(3, t=last)[:, 0, 0].round(3))

try:
    TVPSVAR(sv, order=["y2", "y1"])
except Exception as err:
    print(type(err).__name__)

reordered = TVPSVAR(tvp, order=["y2", "y1"]).identify()
b = reordered.impact(0)
print(bool(np.allclose(b @ b.T, tvp.sigma_u)), round(b[1, 0], 3))

The reordered homoskedastic impact is the Cholesky factor in the new order written back into the original positions: it still reproduces sigma_u, but it is upper triangular in the order of names.

irf(horizon, t=...) freezes the coefficients and the impact at date t’s posterior means. Both are plug-ins: the impact is averaged over draws before it is combined with the averaged coefficient path, so the response is not the posterior mean of the response. For bands, propagate tvp.beta_draws (and h_draws, impact_draws) draw by draw.

Convergence and seeds#

fit takes n_draws (default 2000), n_burn (1000), thin (2), k_drift, k_vol (SV only) and seed (integer or Generator); ceil((n_draws - n_burn) / thin) draws are kept (n_kept). The draws form one Markov chain; read it with convergence() (see The Bayesian workflow):

check = tvp.convergence()
print(check.n_chains, check.n_draws, check.converged)

1 60 False

Sixty draws do not converge, as expected. TVPSVARResult keeps no draws of its own; its convergence() raises, so read the source result’s.

Markov-switching VAR#

The model#

\[y_t = D_{S_t} d_t + \sum_{i=1}^{p} A_{i, S_t}\, y_{t-i} + u_t, \qquad u_t \mid S_t = m \sim N(0, \Sigma_m), \qquad \Pr(S_t = j \mid S_{t-1} = i) = P_{ij},\]

with \(S_t\) a latent first-order Markov chain and each of the deterministic block, the lag block and the covariance either switching or common (Krolzig, 1997). Estimation is EM on the Hamilton filter and Kim smoother; the M-step updates \(P\) from expected transition counts and all regimes’ coefficients in one probability-weighted GLS system, so a common block is estimated jointly. The likelihood is multimodal: fit screens several starts and refines the best.

from cultivars.multivariate.regime_switching.markov_switching import (
    MarkovSwitchingSVAR,
    MarkovSwitchingVAR,
)

rng = np.random.default_rng(12)
P = np.array([[0.95, 0.05], [0.10, 0.90]])
chain = np.zeros(300, dtype=int)
for t in range(1, 300):
    chain[t] = rng.choice(2, p=P[chain[t - 1]])
means = np.array([[0.5, 0.3], [-1.0, -0.5]])
scales = np.array([0.5, 1.0])
A = np.array([[0.4, 0.1], [0.0, 0.3]])
z = np.zeros((300, 2))
for t in range(1, 300):
    z[t] = means[chain[t]] + A @ z[t - 1] + scales[chain[t]] * rng.standard_normal(2)

model = MarkovSwitchingVAR(z, order=1, n_regimes=2, names=["g", "r"])
msvar = model.fit(seed=0, n_init=4)
print(msvar.specification, msvar.label_ordering, msvar.converged)
print(msvar.nobs, msvar.n_params)
print(msvar.transition.round(3))
print(msvar.expected_durations.round(1), round(msvar.regime_uncertainty, 3))

Regimes are sorted by the first variable’s intercept (ascending), so regime 0 is the low-mean regime, which in this simulation is the volatile one (chain state 1). label_ordering names the rule: first-variable intercept when the mean switches, else covariance log-determinant, else the first own-lag coefficient.

probabilities(kind) returns "smoothed" (default), "filtered" or "predicted" posteriors of shape (nobs, M). most_likely_regime is the pointwise smoothed argmax, not a Viterbi path. regime(m) returns the regime’s closed-system view: its coefficients, deterministic, sigma_u, weight (the smoothed probability), nobs (the expected number of periods in the regime, a float), stability_check() and ma_representation(). The same object is returned on every call. regime_table() prints log-determinants, largest roots, ergodic probabilities, durations and realized shares per regime.

Fit arguments are those of MarkovSwitchingAR (max_iter=500, tol=1e-6, n_init=10, screen_iter=15, seed=None); constructor flags switching_mean=True, switching_variance=True, switching_ar=False. A switching mean needs a deterministic term, so trend="n" with switching_mean=True raises.

Structural identification per regime#

Conditional on the chain sitting in regime \(m\) the model is a linear VAR, and regime(m) is accepted by every identification scheme in cultivars.multivariate.structural (see Structural identification). MarkovSwitchingSVAR packages one declaration applied in every regime (Sims, Waggoner and Zha, 2008). With no arguments it applies RecursiveSVAR in the order of names (or order=); alternatively pass one point-identified result per regime, each built from that fit’s own msvar.regime(m):

from cultivars.multivariate.structural.zero_restrictions import RecursiveSVAR

mssvar = MarkovSwitchingSVAR(msvar).identify()
print(mssvar.shock_names, mssvar.impact(0).round(2).tolist())
print(mssvar.impact(1).round(2).tolist(), mssvar.irf(4, regime=1).shape)

per_regime = [
    RecursiveSVAR(msvar.regime(m), order=["r", "g"]).identify() for m in range(2)
]
packaged = MarkovSwitchingSVAR(msvar, per_regime).identify()
print(packaged.shock_names, type(packaged.structural(0)).__name__)

irf(horizon, regime=m) assumes the chain stays in regime m over the whole horizon; read it against expected_durations[m] (8.9 periods for regime 0 here). Responses that integrate over the chain’s future path are not offered.

How the pieces connect#

  • Linear baseline. TVAR, STVAR and MS-VAR results rank against a linear VAR through compare (common nobs required); see Vector autoregressions.

  • Structural layer. Only the MS-VAR exposes closed linear systems (regime(m)) that the schemes in Structural identification accept. TVAR, STVAR, FC-VAR and QVAR results cannot be passed to RecursiveSVAR or any other scheme; their orthogonalized irf (where offered) is a recursive Cholesky in the order of names. The TVP family has its own recursive wrapper, TVPSVAR.

  • Bayesian tools. TVP results carry convergence() from cultivars.bayes.chains; the constant-coefficient counterparts are BVAR and BVARSV in Bayesian VARs. See The Bayesian workflow for diagnostics.

  • State space. The TVP sampler runs on the linear-Gaussian simulation smoother of State-space models and filtering; the MS-VAR filter is the Hamilton and Kim machinery shared with MarkovSwitchingAR.

  • Univariate counterparts. SETAR, LSTAR/ESTAR and MS-AR in Nonlinear and regime-switching univariate models, where the linearity tests also live.

  • Forecast evaluation. TVAR and STVAR give a skeleton multi-step path; FC-VAR and QVAR give one step; TVP and MS-VAR results have no forecast method. Plan forecast comparisons (Forecasting and forecast evaluation) accordingly.

Nuances and gotchas#

  • No standard errors on any estimator here except the kernel pointwise bands of FC-VAR (conditional on the bandwidth) and the posterior bands of the TVP models.

  • No generalized (history-averaged) impulse responses. Every irf is a frozen-regime, frozen-state, frozen-quantile or frozen-date linearization.

  • Regime names differ by family. Observed-regime models take regime="lower" / "upper"; the MS-SVAR takes an integer regime. For an exponential STVAR, “upper” is both tails.

  • Missing methods. MarkovSwitchingVARResult has no forecast, simulate or irf (identify first, then use MarkovSwitchingSVARResult.irf). TVP results have no forecast, irf (use TVPSVAR) or likelihood. FC-VAR and QVAR results have no compare.

  • Delay searching. Only a self-exciting TVAR searches the delay (delay=None). STVAR and FC-VAR default to delay=1 and never search; an external-driver TVAR must state its delay.

  • Parameter counts. TVARResult.n_params counts both regimes’ coefficients, both covariances and the threshold (19 above); STVARResult.n_params counts one covariance, the threshold and gamma (17). Neither counts a searched delay.

  • ``gamma`` is a lower bound when abrupt. If is_effectively_abrupt is True, use TVAR. For the exponential form the flag is always False.

  • Effective samples. Observed-regime models drop max(order, delay) rows; TVP models also drop training rows, and every path is indexed on what remains; compare raises DimensionError on unequal nobs.

  • TVP prior scales are findings in disguise. The default k_drift = k_vol = 0.01 produce nearly flat paths on moderate drift; report results under several values.

  • TVP run time. The sampler loops over dates in Python: about 0.02 seconds per iteration for a bivariate VAR(1) with 90 estimation rows and about 0.08 with 160, so the default 2000 draws take one to three minutes on a small system. Scale n_draws accordingly when exploring.

  • TVPVARSV ``sigma_u`` is the posterior mean of the time-averaged covariance \(T^{-1}\sum_t \Sigma_t\), not the end-of-sample covariance; use h_draws and impact_draws for date-specific covariances.

  • TVPSVAR with SV is fixed at estimation. Reorder the columns of endog and refit to change the recursive ordering.

  • MS-VAR convergence flag. When the refining EM run ends below the best screened log-likelihood, the fit falls back to the screened start and reports converged=False with n_iter == screen_iter, and the summary opens with a non-convergence warning. This happens often on well-behaved data. Refit with another seed or larger n_init; if the log-likelihood matches across seeds, the optimum is likely found despite the flag.

  • MS-VAR regime views. regime(m).nobs is a float (expected periods) and regime(m).resid is probability-weighted; schemes that read only the covariance are unaffected, schemes that read residual moments consume a weighted object.

  • lag_order_selection scores the linear VAR. The method inherited by every model on this page fits linear VAR(\(p\)) orders, not the nonlinear model. With max_lags=None it scores every order up to the largest the sample supports, where the residual covariance becomes nearly singular and all criteria can pick the maximum; always pass max_lags.

  • QVAR levels. Accessors refuse any level not in quantiles; the quantiles passed to fit are sorted ascending.

  • FC-VAR extrapolation. coefficients_at, irf and forecast raise when the state lies outside the trimmed state_range.
