Diagnostics and specification testing#

cultivars.diagnostics holds the tests you run before a model is chosen: does a series carry a stochastic trend, is its seasonal pattern fixed, how many cointegrating relations does a system have, did the regression break, is a linear autoregression wrong in the way a regime model would fix. Every test returns a record with one reject and one summary, and the tests a fitted model runs on its own residuals (portmanteau, normality, ARCH, Granger causality) return the same records from the result object. This page does not cover forecast comparison tests (see Forecasting and forecast evaluation) or MCMC convergence diagnostics (see The Bayesian workflow).

The test record#

Every hypothesis test descends from HypothesisTest, which holds two fields, statistic and pvalue (possibly None), and two methods: reject(*, alpha=0.05) and summary(). summary() returns a SummaryTable (to_text, to_pandas, to_polars); print(record) renders that table and repr(record) is a one-line verdict. A study that collects a dozen verdicts therefore holds one kind of object.

import numpy as np
from cultivars.diagnostics.unit_roots import adf, dfgls, kpss, ng_perron

rng = np.random.default_rng(0)
walk = np.cumsum(rng.standard_normal(300))
test = adf(walk)
print(test)

Unit roots and stationarity#

The Dickey-Fuller family tests \(\gamma = 0\) in

\[\Delta y_t = d_t + \gamma\, y_{t-1} + \sum_{j=1}^{p} \phi_j\, \Delta y_{t-j} + e_t,\]

where \(d_t\) is nothing, a constant, or a constant and trend (trend="n", "c", "ct"). Under the null the \(t\) ratio converges to a functional of Brownian motion whose quantiles sit far left of the normal’s (Dickey and Fuller 1979). KPSS reverses the null (Kwiatkowski et al. 1992): it regresses \(y_t\) on \(d_t\) and scales the squared partial sums of the residuals by a long-run variance estimate,

\[\eta = \frac{T^{-2} \sum_{t=1}^{T} S_t^2}{\hat\lambda^2}, \qquad S_t = \sum_{i \le t} \hat e_i ,\]

rejecting in the upper tail. The module offers:

  • adf(): augmented Dickey-Fuller, augmentation chosen on a common sample, MacKinnon (1996) p-values (Said and Dickey 1984).

  • phillips_perron(): the un-augmented \(t\) with a kernel correction (Phillips and Perron 1988).

  • dfgls(): GLS-detrended Dickey-Fuller (Elliott, Rothenberg and Stock 1996), more powerful near the null; pvalue=None.

  • ng_perron(): the \(M\) statistics (Ng and Perron 2001), sized correctly under a negative MA root; pvalue=None.

  • zivot_andrews(): unit root against a one-time break at an unknown date (Zivot and Andrews 1992); pvalue=None.

  • kpss(): stationarity null.

  • long_run_variance(): the Bartlett or quadratic-spectral kernel estimator the corrected tests divide by.

There is no Phillips-Perron \(Z_\alpha\), no Lumsdaine-Papell or Lee-Strazicich two-break test, and no panel unit-root test.

rng = np.random.default_rng(0)
T = 300
walk = np.cumsum(rng.standard_normal(T))
ar = np.zeros(T)
for t in range(1, T):
    ar[t] = 0.6 * ar[t - 1] + rng.standard_normal()
trending = 0.05 * np.arange(T) + ar

for f in (adf, kpss):
    for name, y in (("walk", walk), ("ar", ar)):
        rec = f(y)
        print(f"{rec.name:<5} {name:<5} stat={rec.statistic:7.3f}  "

def classify(y, trend="c"):
    unit = adf(y, trend=trend).reject()
    stationary = kpss(y, trend=trend).reject()
    if unit and not stationary:
        return "I(0)"
    if stationary and not unit:
        return "I(1)"
    return "both reject" if unit else "neither rejects"

for name, y in (("walk", walk), ("ar", ar), ("trending", trending)):
    print(f"{name:<9} trend='c': {classify(y):<6} trend='ct': {classify(y, 'ct')}")

walk      trend='c': I(1)   trend='ct': I(1)
ar        trend='c': I(0)   trend='ct': I(0)
trending  trend='c': I(1)   trend='ct': I(0)

The trending row is the standard trap: a trend-stationary series tested with trend="c" looks integrated. The deterministic terms must include everything the stationary alternative needs.

The true long-run variance of this AR(1) is \(1/(1 - 0.6)^2 = 6.25\); the Newey-West default (5 lags here) reaches about half of it, and a wider bandwidth moves closer. KPSS and Phillips-Perron inherit that downward bias on persistent series.

Seasonal unit roots#

Seasonal differencing removes a unit root at every frequency \(\omega_k = 2\pi k / s\),

\[1 - L^s = (1 - L)(1 + L) \prod_{k=1}^{s/2-1} \bigl(1 - 2\cos\omega_k\, L + L^2\bigr),\]

and a series rarely needs all of them. HEGY (Hylleberg, Engle, Granger and Yoo 1990) tests each factor in one regression with the seasonal random walk as the null: \(t\) statistics at \(\omega = 0\) and \(\pi\) (lower tail), \(F\) statistics for each complex pair and two joint \(F\) statistics (upper tail). Canova and Hansen (1995) reverse the null, as KPSS does at frequency zero. Both read p-values from laws simulated at the sample size, period and deterministic set in hand, so the seed matters and replications/n_draws set the p-value resolution.

from cultivars.diagnostics.seasonality import canova_hansen, hegy

rng = np.random.default_rng(5)
T = 160
pattern = np.tile([1.0, -0.5, 2.0, -2.5], T // 4)
y = np.cumsum(rng.standard_normal(T)) + pattern

root = hegy(y, period=4, replications=500, seed=0)
for rec in (root, *root.companions):
    print(f"{rec.name:<38} lower_tail={rec.lower_tail!s:<5} "
          f"p={rec.pvalue:.3f}  reject={rec.reject()}")
print(root.trend, root.lags, root.method)

Long memory#

For \((1 - L)^d y_t = u_t\) with short-memory \(u_t\), the spectrum behaves as \(f(\lambda) \sim c\,\lambda^{-2d}\) near the origin, and the three semiparametric estimators read \(d\) off the \(m\) lowest Fourier frequencies: gph() (Geweke and Porter-Hudak 1983; s.e. \(\pi/\sqrt{24 m}\), valid for \(d < 1/2\)), local_whittle() (Robinson 1995; s.e. \(1/(2\sqrt{m})\), limit theory for \(d < 3/4\)) and exact_local_whittle() (Shimotsu and Phillips 2005; valid for any \(d\)). The record is an estimate first: d and se, with statistic and pvalue testing \(d = 0\). test(null) re-aims the test without re-estimating.

from cultivars.diagnostics.long_memory import gph, local_whittle

rng = np.random.default_rng(9)
T, d = 800, 0.35
psi = np.empty(T)
psi[0] = 1.0
for k in range(1, T):
    psi[k] = psi[k - 1] * (k - 1 + d) / k   # MA weights of (1 - L)^(-d)
y = np.convolve(rng.standard_normal(T), psi)[:T]

for f in (gph, local_whittle, exact_local_whittle):
    est = f(y)
    low, high = est.confidence_interval()
    print(f"{est.method:<20} d={est.d:6.3f} se={est.se:.3f} m={est.bandwidth:<3} "
          f"95% CI=({low:.2f}, {high:.2f})")

gph                  d=-0.144 se=0.146 m=28  95% CI=(-0.43, 0.14)
local_whittle        d= 0.286 se=0.057 m=77  95% CI=(0.17, 0.40)
exact_local_whittle  d= 0.296 se=0.057 m=77  95% CI=(0.18, 0.41)

On a random walk, local_whittle stops at its search bound of one and the summary says to switch estimators; exact_local_whittle searches up to two:

f_bandwidth sets \(m\) directly; otherwise \(m = \lfloor T^{\text{exponent}} \rfloor\) with exponent 0.5 (GPH) or 0.65 (Whittle). All three need at least 64 observations.

Structural breaks#

Each break function takes a target, optional regressors exog and a trend ("n", "c", "ct"). With exog=None the regression is on the deterministic terms alone, a test for a break in the mean or trend. Every coefficient is allowed to break, and serial correlation and heteroskedasticity are not corrected: include lags of the target in exog for a dynamic regression.

sup_wald() (Andrews 1993) computes at each date \(T_b\) in the trimmed window the Wald statistic

\[W(T_b) = \frac{S_0 - S_1(T_b)}{S_1(T_b) / (T - 2q)},\]

and reports the sup, with Andrews and Ploberger’s (1994) exp-Wald and ave-Wald as companions. The p-values come from n_draws simulated Brownian-bridge paths at the trimming in use.

from cultivars.diagnostics.breaks import bai_perron, cusum

rng = np.random.default_rng(3)
y = np.concatenate([rng.standard_normal(120), 1.5 + rng.standard_normal(120)])

sw = sup_wald(y, n_draws=1000, grid=500, seed=0)
print(repr(sw))
print([(c.name, round(c.statistic, 2)) for c in sw.companions])
print(sw.n_restrictions, sw.trimming, sw.path.shape, int(np.isnan(sw.path).sum()))

path holds \(W(T_b)\) at every date (nan outside the window), so the Chow-type statistic at a date fixed in advance is sw.path[tb], asymptotically \(\chi^2_q\) at a known date. There is no separate Chow function.

bai_perron() (Bai and Perron 1998, 2003) finds the global least-squares partition for every break count up to max_breaks by dynamic programming and selects the count by BIC (default), LWZ (Liu, Wu and Zidek 1997) or the sequential \(\sup F(l+1 \mid l)\) procedure. All three are computed on every call:

bp = bai_perron(y, max_breaks=3, n_draws=1000, grid=500, seed=0)
print(bp)
print(bp.partitions)
print(bp.bic.round(3), int(np.argmin(bp.lwz)))
print([(s.name, round(s.pvalue, 3), s.break_index) for s in bp.sequential])

cs = cusum(y)

Cointegration rank#

Johansen’s (1991) reduced-rank regression estimates the squared canonical correlations \(\hat\lambda_1 \ge \cdots \ge \hat\lambda_k\) between differences and lagged levels and tests the rank with

\[\lambda_{\text{trace}}(r) = -T \sum_{i=r+1}^{k} \ln(1 - \hat\lambda_i), \qquad \lambda_{\max}(r) = -T \ln(1 - \hat\lambda_{r+1}).\]

The test is a method of the error-correction model, VECM(...).rank_test(), and returns the JohansenRankTest record. It does not depend on the rank the model was built with, so build with rank=0. P-values are empirical over simulations draws of the Johansen limit for the deterministic case (cointegration_trend: "none", "restricted_constant", "constant", "restricted_trend", "trend"; Johansen 1995) and, for a VECMX, for the number of weakly exogenous I(1) regressors (Pesaran, Shin and Smith 2000).

from cultivars.multivariate.reduced_form.error_correction import VECM

rng = np.random.default_rng(7)
T = 300
common = np.cumsum(rng.standard_normal(T))
levels = np.column_stack([
    common + rng.standard_normal(T),
    0.5 * common + rng.standard_normal(T),
    np.cumsum(rng.standard_normal(T)),
])
rank_test = VECM(levels, order=2, rank=0).rank_test(simulations=1000, steps=200)
print(rank_test)
print(rank_test.trace_statistic.round(2), rank_test.trace_pvalue.round(3))
print(rank_test.max_eigenvalue_pvalue.round(3))
print(rank_test.selected_rank(), rank_test.selected_rank(statistic="max_eigenvalue"))

JohansenRankTest(k=3, nobs=298, deterministic='constant', trace_rank=1, max_eigenvalue_rank=1)
[142.03  16.23   1.65] [0.    0.074 0.629]
[0.    0.056 0.629]
1 1

selected_rank stops at the first rank not rejected, returning k if all are rejected (stationary in levels). to_table() renders both sequences with notes on the sequential size and the p-value resolution (\(1/\text{simulations}\)). small_sample=True applies the Reinsel and Ahn (1992) scaling \((T - kp)/T\), which pulls the asymptotic test’s over-rejection in short samples (about 7% at nominal 5% for three variables and 400 observations, per the method docstring) back toward its level.

The selected rank feeds the model; see Beyond the basic VAR for the VECM itself.

res = VECM(levels, order=2, rank=rank_test.selected_rank(),
           names=["a", "b", "c"]).fit()
print(res.normalized_beta().round(2).ravel())
print(repr(res.weak_exogeneity("c")))

[ 1.   -2.03  0.05]
WaldTest(statistic=0.0148, df=1, pvalue=0.9033, keep at 5%: 'c is weakly exogenous for the cointegrating space')

Nonlinearity#

The four model-aimed tests fit the linear AR(order) internally, so pass the series, not residuals. Each returns a LinearityTest naming its alternative.

  • terasvirta() (Teräsvirta 1994): third-order Taylor expansion of a smooth transition in \(y_{t-d}\), an \(F(3p, n - 4p - 1)\) test; its companions H04, H03, H02 give suggestion ("LSTAR" or "ESTAR").

  • tsay() (Tsay 1989): arranged autoregression sorted by \(y_{t-d}\); threshold alternative, no threshold estimate.

  • ramsey_reset() (Ramsey 1969): powers \(2..k\) of the fitted value; names no regime.

  • hansen_threshold() (Hansen 1996): sup-\(F\) over a threshold grid with a fixed-regressor bootstrap p-value; reports threshold, the selected delay and simulated critical_values, with df=None.

  • bds() (Brock et al. 1996): independence against any dependence, run on residuals; record at dimension with lower dimensions as companions.

from cultivars.diagnostics.nonlinearity import bds, hansen_threshold, ramsey_reset, terasvirta

rng = np.random.default_rng(21)
T = 300
y = np.zeros(T)
for t in range(1, T):
    y[t] = (0.7 if y[t - 1] <= 0.0 else -0.4) * y[t - 1] + rng.standard_normal()

for f in (terasvirta, tsay, ramsey_reset):
    rec = f(y, order=1)
    print(f"{rec.name:<11} {rec.alternative:<24} df={rec.df}  reject={rec.reject()}")
tv = terasvirta(y, order=1)
print(tv.suggestion, [(c.name, round(c.pvalue, 3)) for c in tv.companions])

Teräsvirta  smooth transition        df=(3, 294)  reject=True
Tsay        threshold                df=(2, 244)  reject=True
RESET       smooth misspecification  df=(2, 295)  reject=True
LSTAR [('H04', 0.797), ('H03', 0.005), ('H02', 0.0)]

hansen_threshold defaults to replications=1000 and n_grid=300; a smaller run is enough to read a strong rejection:

h = hansen_threshold(y, order=1, replications=200, n_grid=100, seed=0)
print(repr(h))
print(round(h.threshold, 3), h.delay, h.df, round(h.critical_values["5%"], 2))

LinearityTest(name='Hansen sup-F', statistic=40.4489, pvalue=0, order=1, nobs=299)
-0.212 1 None 10.7

BDS rejects for any dependence, so read it after an ARCH test, not instead of one. The model-aimed tests are not immune either: on this ARCH(1) series, which has no regime in its mean, Tsay rejects linearity as well as BDS, because neglected conditional heteroskedasticity inflates it. Run the ARCH test on the linear residuals first:

e = np.zeros(600)
for t in range(1, 600):
    e[t] = np.sqrt(0.2 + 0.7 * e[t - 1] ** 2) * rng.standard_normal()
b = bds(e)
print(tsay(e, order=1).reject(), b.reject(), b.dimension, [c.dimension for c in b.companions])
print(round(b.epsilon / e.std(), 2))

True True 3 [2]
1.5

The record’s summary warns when nobs < 500, where the normal reference over-rejects (about 8% at nominal 5% on 250 Gaussian observations per the class docstring).

Stability and lag order#

cultivars.diagnostics.stability documents two records that fitted results produce. StabilityAssessment holds the companion eigenvalues, max_modulus, is_stable, n_unit_roots and n_explosive at a tolerance tol (default 1e-8). It is deterministic: no null, no p-value. VAR-family results return it from stability_check(); ARMA-family results expose stability and invertibility properties. The class methods assess_stability, assess_stability_from_companion, is_stationary and is_invertible work on raw coefficients.

from cultivars.diagnostics.stability import StabilityAssessment

A = np.array([[[0.5, 0.2], [0.0, 0.4]]])
check = StabilityAssessment.assess_stability(A)
print(check.is_stable, round(check.max_modulus, 2), check.n_unit_roots)
walk_check = StabilityAssessment.assess_stability([1.0])
print(walk_check.is_stable, walk_check.n_unit_roots, walk_check.n_explosive)
print(StabilityAssessment.assess_stability([1.0], allow_unit_roots=True).is_stable)

True 0.5 0
False 1 0
True

A VECM carries \(k - r\) unit roots by construction and its stability_check() passes allow_unit_roots=True; with the rank-one model above:

vecm_check = res.stability_check()

LagOrderSelection comes from model.lag_order_selection(max_lags=...) on any VAR-family model. It scores every order on one common sample and keeps the whole AIC, BIC, HQIC and FPE curves; best(criterion), selected, consensus (None when the criteria disagree) and to_table() read them.

from cultivars.multivariate.reduced_form.vector_autoregression import VAR

rng = np.random.default_rng(1)
T = 250
x = np.zeros((T, 2))
for t in range(1, T):
    x[t] = A[0] @ x[t - 1] + rng.standard_normal(2)
selection = VAR(x, order=1, names=["x", "z"]).lag_order_selection(max_lags=4)
print(selection)
print(selection.consensus, selection.nobs, selection.curve("bic").round(3))

Residual diagnostics on fitted results#

Fitted VAR-family results (VAR, VARX, VECM, VECMX, VARMA, PanelVAR, MIDASVAR; see Vector autoregressions) run their own residual tests and return WaldTest records whose null is a sentence:

  • portmanteau_test(lags=10): multivariate Ljung-Box statistic (Hosking 1980 adjustment) on the residual autocorrelations.

  • normality_test(variable): Jarque-Bera on one equation’s residuals, 2 degrees of freedom. There is no multivariate (Lütkepohl) normality test.

  • arch_test(variable, lags=5): Engle’s (1982) LM test, \((n - \text{lags}) R^2\) from squared residuals on their lags.

  • granger_causality(cause, effect): Wald test that cause’s lags are jointly zero in effect’s equation.

  • likelihood_ratio_test(unrestricted): a LikelihoodRatioTest against a larger model on the same sample.

  • residual_diagnostics(portmanteau_lags=10, arch_lags=5): all of the first three in one SummaryTable (not a record).

fit = VAR(x, order=1, names=["x", "z"]).fit()
print(fit.residual_diagnostics())
print(repr(fit.granger_causality("z", "x")))

from cultivars.exceptions import DimensionError

    fit.likelihood_ratio_test(long_fit)
except DimensionError as err:
    print(err)
short_fit = VAR(x[1:], order=1, names=["x", "z"]).fit()
print(repr(short_fit.likelihood_ratio_test(long_fit)))

Univariate results (ARResult, ARMAResult, GARCHResult) carry no residual tests of their own: no Ljung-Box, no Jarque-Bera, no ARCH LM. The tools at hand are the stability/invertibility properties and bds() on result.resid:

arma = ARIMA(z, order=(1, 0, 0)).fit()

A recommended pre-estimation workflow#

The sequence below takes three level series to a validated VECM: classify each series, check the differences for breaks, choose the lag order, test the cointegrating rank, fit, and check the residuals and the roots. It reuses classify from the confirmatory-analysis section.

rng = np.random.default_rng(1)
T = 400
tau = np.cumsum(rng.standard_normal(T))
u = np.zeros((T, 3))
for t in range(1, T):
    u[t] = 0.5 * u[t - 1] + rng.standard_normal(3)
data = np.column_stack([tau + u[:, 0], 0.5 * tau + u[:, 1], np.cumsum(u[:, 2])])
names = ["y1", "y2", "y3"]

# 1. Order of integration: levels, then first differences.
print([classify(data[:, j]) for j in range(3)])
print([classify(np.diff(data[:, j])) for j in range(3)])

# 2. No break in the mean of any difference.
print([sup_wald(np.diff(data[:, j]), n_draws=1000, grid=500, seed=0).reject()
       for j in range(3)])

# 3. Lag order of the levels VAR, on a common sample.
order = VAR(data, order=1, names=names).lag_order_selection(max_lags=6).best("bic")
print(order)

# 4. Cointegrating rank.
ranks = VECM(data, order=order, rank=0, names=names).rank_test(
    simulations=2000, steps=200)
rank = ranks.selected_rank()
print(rank, ranks.trace_pvalue.round(3))

# 5. Fit at the selected rank and check what the fit left behind.
vecm = VECM(data, order=order, rank=rank, names=names).fit()

print(round(vecm.portmanteau_test(10).pvalue, 3),

The cointegrating vector recovers \(y_1 - 2 y_2\) (the true relation), the third series is excluded, the residuals show no autocorrelation or ARCH at 5%, and the companion has exactly \(k - r = 2\) unit roots and none outside the circle. Add the seasonal step (hegy with canova_hansen) before step 1 for sub-annual data, and the nonlinearity step (arch_test on the residuals, then tsay/terasvirta) after step 5 if a regime model is a candidate (see Nonlinear and regime-switching univariate models and Nonlinear, time-varying and regime-switching VARs).

How the pieces connect#

  • Unit-root and seasonal tests decide between a levels model, a differenced ARIMA/SARIMA (Univariate linear models) and a cointegrated system (Beyond the basic VAR).

  • rank_test lives on VECM and VECMX; its record decides the rank argument of the model you then fit.

  • Long-memory estimates point to ARFIMA or FIGARCH (Univariate linear models, Volatility models).

  • Linearity rejections license SETAR, LSTAR and ESTAR (Nonlinear and regime-switching univariate models).

  • Residual tests, Granger causality and lag selection sit on the fitted VAR-family results (Vector autoregressions), and stability is presumed by every impulse response and forecast (Structural identification, Forecasting and forecast evaluation).

  • Forecast-comparison tests return records from the same family but live in cultivars.forecast.comparison; MCMC convergence reports live in cultivars.bayes.chains (The Bayesian workflow).

Nuances and gotchas#

Which tail rejects. Dickey-Fuller-family records, Zivot-Andrews and HEGY t rows have lower_tail=True; KPSS, Canova-Hansen, HEGY F rows, every break test and every linearity test reject in the upper tail. Ng-Perron’s \(MSB\) and \(MP_T\) are positive yet reject when small. reject() handles all of this; read lower_tail before comparing a statistic with a critical value by hand.

KPSS p-values are clipped, and reject() takes them literally. The p-value is interpolated in a four-point table and clipped to [0.01, 0.10]. Two consequences follow, both verified:

rng = np.random.default_rng(42)
strong = kpss(np.cumsum(rng.standard_normal(250)))
print(round(strong.statistic, 2), strong.critical_values["1%"], strong.pvalue,
      strong.reject(alpha=0.01))
weak = kpss(rng.standard_normal(250))
print(round(weak.statistic, 3), weak.pvalue, weak.reject(alpha=0.20))

3.69 0.739 0.01 False
0.087 0.1 True

A statistic five times the 1% critical value does not “reject at 1%” (0.01 < 0.01 is false), and any KPSS record rejects at a level above 10%, however small its statistic. Use alpha in (0.01, 0.10] with KPSS, or compare statistic with critical_values directly.

Simulated p-values have a resolution. sup_wald, bai_perron, cusum(squares=True), hegy, canova_hansen, hansen_threshold and rank_test report the share of simulated draws at or beyond the statistic. A p-value of 0 means below 1 / n_draws (or replications, simulations). Pass seed for reproducibility; the default seed=None gives a different p-value on each call. rank_test alone fixes its seed (20260819) by default.

Tables without p-values. DF-GLS, Ng-Perron, Zivot-Andrews and the CUSUM carry pvalue=None and accept only alpha in {0.01, 0.05, 0.10}; any other level raises SpecificationError. DF-GLS’s asymptotic critical values are mildly liberal (about 6% size at nominal 5% with 100 observations, per its docstring).

Small-sample size notes carried by the records. Johansen’s trace test over-rejects in short samples (use small_sample=True); BDS over-rejects below 500 observations and its summary says so; the long-memory standard errors are asymptotic in the bandwidth and the 95% interval covers 90 to 94% at 500 observations (low 80s for exact local Whittle near \(d = 1/2\)); KPSS over-rejects on persistent stationary series, Phillips-Perron under a large negative MA root.

Lag selection defaults differ across tests. ADF and HEGY select by AIC, DF-GLS and Ng-Perron by the modified AIC ("maic"), and Zivot-Andrews by the t-statistic rule, all up to Schwert’s ceiling. The modified AIC selects long augmentations on series far from the null (six lags on the AR(0.6) above, against none for AIC); pass method="aic" or a fixed lags there. KPSS and Phillips-Perron use a Newey-West bandwidth; Canova-Hansen adds lags=0 lags of the series by default.

Reported bandwidth under the quadratic-spectral kernel. With kernel="quadratic-spectral" and bandwidth=None, KPSS and Phillips-Perron compute the long-run variance with Andrews’ plug-in bandwidth, but the record’s lags field still reports the Newey-West Bartlett rule. Pass bandwidth explicitly if the reported value matters.

The VAR portmanteau degrees of freedom. portmanteau_test uses \(k^2 h - k \cdot m\) degrees of freedom, where \(m\) counts every regressor per equation, deterministic terms included. The textbook figure is \(k^2 (h - p)\) (Lütkepohl 2005), so with a constant the reported df is k smaller (34 instead of 36 for the bivariate VAR(1) above) and the p-value slightly smaller. It also requires k * k * lags to exceed that count; lags=1 raises.

No Engle-Granger test. There is no residual-based cointegration test. Running adf on OLS residuals from a cointegrating regression does not give one: the residuals are fitted to look stationary, and the Dickey-Fuller p-values are far too small for them (the correct MacKinnon cointegration surfaces are not in the package). Use rank_test.

Breaks: what the records do not do. No partial breaks (every coefficient breaks), no HAC correction, no Chow function (use sup_wald(...).path[tb] against \(\chi^2_q\)). bai_perron’s partitions are not nested across counts, and its sequential tests run under every criterion, so n_draws governs the cost even with criterion="bic". break_index is the first observation of the new regime; for Zivot-Andrews and sup-Wald it is reported whether or not the null is rejected.

HEGY’s simulated null uses no augmentation. The HEGY draws run the regression with zero lags on the full sample length, whatever lags the test selected. A brief check (80 seasonal random walks of 160 observations) gave rejection rates of 4% to 8% at nominal 5%.

Long memory. local_whittle cannot report \(d > 1\); an estimate of exactly 1.0 is the search bound, and test(1.0) then “keeps” a unit root by construction. reject() on a fresh LongMemoryEstimate tests \(d = 0\), not a unit root. GPH is valid only for \(d < 1/2\); difference first or use exact_local_whittle.

Linearity tests. Teräsvirta’s suggestion is set even when linearity is kept; read it only after reject(). Neglected ARCH inflates all four model-aimed tests, and hansen_threshold assumes homoskedastic errors. The transition variable is always a lag of the series; exogenous transition variables are not covered. hansen_threshold requires replications >= 200.

StabilityAssessment.is_invertible takes negated MA coefficients. The class methods test \(1 - c_1 z - \cdots - c_q z^q\), the AR convention. For \(\theta(L) = 1 + \theta_1 L + \theta_2 L^2\) pass -theta:

theta = np.array([1.5, 0.6])   # 1 + 1.5 L + 0.6 L^2, invertible
print(StabilityAssessment.is_invertible(theta), StabilityAssessment.is_invertible(-theta))

False True

Fitted ARMA results negate internally; the trap is only in calling the class method yourself.

Records that are not tests. JohansenRankTest and LagOrderSelection render with to_table(), not summary(). MultipleBreakTest has summary() but no reject. residual_diagnostics() returns a table, not records; call the individual methods to get objects you can reject.
