Examples#

Worked examples for cultivars, one script per model family. Each script is executed at documentation-build time, so the figures and printed output are produced by the code shown. Scripts are plain Python with reST in the module docstring and in # %% cell comments; run any of them directly with python examples/plot_<name>.py.
