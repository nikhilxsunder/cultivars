Choosing a model#

Start from the question, not the class list. The tables below map common research questions to the class that answers them and to the page that explains it. Run the Diagnostics and specification testing first: whether a series has a unit root, is cointegrated or behaves nonlinearly decides half of the choices below.

Point estimates or posteriors?#

Most reduced forms come in a frequentist and a Bayesian version, and the choice changes what you get back:

Frequentist (VAR, ARIMA, …)

Bayesian (BVAR, GibbsBVAR, SV, …)

Fit returns

point estimates, sampling covariance

posterior draws, credible intervals

Model choice

compare on information criteria, LR tests

marginal likelihood, model averaging (The Bayesian workflow)

Forecasts

forecast (point)

forecast_paths (predictive sample)

Identification

every scheme accepts the result

not yet: Bayesian results are not closed systems

Cost

milliseconds

seconds to minutes; set n_draws and seed

A prior= argument on VAR sits between the two. It shrinks the point estimate toward the prior mean but keeps a VAR result, which can still be identified; see Bayesian VARs.
