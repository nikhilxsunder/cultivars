API reference#

Every public name lives in one of the subpackages below; nothing is re-exported from the top-level cultivars namespace. Names beginning with an underscore, and the _core and _internals packages, are implementation detail and may change between releases without notice.

cultivars.univariate

Cultivars univariate time series module.

cultivars.multivariate

Cultivars vector autoregressive (VAR) module.

cultivars.state_space

State-space substrates: linear-Gaussian, nonlinear, and regime-switching.

cultivars.bayes

Cultivars Bayesian module.

cultivars.diagnostics

Diagnostics: test records; unit-root, break, nonlinearity, long-memory, and MCMC checks.

cultivars.forecast

Forecast evaluation: scoring, comparison, and calibration of densities.

cultivars.spectral

Frequency-domain views of fitted systems and data, filters, cycle dating, and wavelets.

cultivars.exceptions

Public exception and warning hierarchy for cultivars.
